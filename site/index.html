myself REMEMBER

Your agent remembers people, projects and decisions across sessions. What it learns lands in one file you own.

Say it, then ask it.

The agent does the thinking. myself keeps what it learned. You can run the same commands yourself.

Install

Available from v0.1. The first release is in progress, so none of this installs yet. Watch the repo on GitHub to hear when it ships.

Use it from Claude Code

  1. 1Install the skill. Copy skill/myself from the repo into ~/.claude/skills/.

  2. 2Start every session with the brief. Add a SessionStart hook to ~/.claude/settings.json that runs myself prime.

  3. 3Allow Bash(myself:*) so permission prompts do not stop the agent.

Other harnesses: any agent that can run shell commands can use myself. myself prime prints a brief to paste into its system prompt.

What you get

  1. Works with the agent you already run

    The agent does the extracting before it calls myself. So there are no extra LLM calls, no server and no API keys, and it works offline.

  2. One binary, called from Bash

    Claude Code, pi and Paseo workers all have Bash. Put the binary on your $PATH, add a skill file, and any of them can use it.

  3. Facts carry time

    A correction replaces the old fact going forward, and the old one stays in the history. Add --at to see what was true on a given date.

  4. Molting: the agent rewrites who it is

    The agent keeps one fact, i am "…", and rewrites it when you correct it. myself history i am shows how it changed.

  5. Dreaming tidies up

    myself dream lists duplicate entities and near-duplicate predicates. The agent merges them with ordinary commands.

  6. One file, in git

    The memory is ~/.myself/brain.jsonl. It diffs, it lives in git, and two memories merge like two branches.

  7. See it in Obsidian

    myself export --obsidian <dir> writes one note per entity with [[wikilinks]], and Obsidian's graph view draws the graph. It is a one-way mirror: edits in the vault do not come back.

Nothing is overwritten.

A correction does not erase the old fact. It stands behind the new one, fainter, and stays readable.

Fourteen commands

remember
save a fact or give an entity a type
forget
retire a fact; it stays in the history
alias
make a second name point at one entity
describe
everything known about one entity, both directions
ls
list entities, optionally of one type
predicates
the verbs in use, with counts
search
find entities and facts by text
path
how two entities connect
log
what was written, newest first
history
every past version of a fact
prime
a short brief for the start of a session
dream
report duplicates and untyped things
export
write the brain out, for example --obsidian
sync
pull and push the brain file through git
